# 別表第五（第三十四条関係）

| 一 | 旧別表第一の二十八の項から三十一の項まで及び三十二の項に掲げる地域 | 千八百八円九十二銭 |

| 二 | 旧別表第一の二の項から二十二の項までに掲げる地域 | 千二百二十三円六十八銭 |

| 三 | 旧別表第一の一の項及び三十一の二の項に掲げる地域 | 千百十七円二十七銭 |

| 四 | 旧別表第一の二十四の項及び二十五の項に掲げる地域 | 千六十四円七銭 |

| 五 | 旧別表第一の二十三の項、二十六の項及び二十七の項並びに三十三の項から三十七の項までに掲げる地域 | 七百九十八円五銭 |

| 六 | 旧別表第一に掲げる地域以外の地域 | 百十八円二十三銭 |
