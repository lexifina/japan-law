# 別表三　生育障害調査の調査内容

| 調査事項 | 調査内容 |

| 日陰 | 原因となる物体の種類、範囲、期間及び時間 |

| 凍霜害 | 範囲、程度 |

| 風害 | 範囲、程度 |

| 雪害 | 程度、期間 |

| 霧害 | 程度、期間 |

| 干ばつ | 範囲、程度、頻度、期間 |

| 冠水 | 範囲、程度、日数、時期、頻度 |

| 塩害（潮風害を含む。） | 範囲、程度、時期、時間 |

| その他の生育障害に関する重要な事項 | たとえば雨害、冷害等の自然現象（病虫害及び鳥獣害を除く。）の種類、範囲、程度等。毒水及び汚濁水、煙害等の人為的原因の種類、程度等 |
