# 別表（第三条関係）

| 一 | 南スーダン内の地域において業務を行う場合（二の項（一）及び三の項本文に規定する場合を除く。） | 一万六千円 |

| 二 | （一）　南スーダン内の地域において、第一条第一号から第三号までに掲げる業務（派遣先国の政府その他の関係機関と当該業務に従事する協力隊の隊員との間の連絡調整に係るものに限る。）又は同条第四号に掲げる業務を行う場合（二）　ウガンダ内の地域において、第一条第一号から第三号までに掲げる業務を行う場合（四の項（一）に規定する場合を除く。）（三）　ウガンダ又はケニア内の地域において、法第三条第五号ワ、ヨからレまで、ツ及びラに掲げる業務並びに第二条第一号から第三号までに掲げる業務（以下「自衛隊の部隊等の業務」という。）に附帯する業務として、自衛隊の部隊等の業務に必要な物資の補給に係る業務を行う場合（四の項（二）及び五の項（二）に規定する場合を除く。）。ただし、陸上において行う場合に限る。 | 六千円 |

| 三 | 南スーダンに所在する空港の区域において、自衛隊の部隊等の業務に附帯する業務として、空路により自衛隊の部隊等の業務に従事する人員の輸送又は自衛隊の部隊等の業務に必要な物資の補給を行う場合。ただし、陸上の場所に留まって行う場合に限る。 | 四千円 |

| 四 | （一）　ウガンダ内の地域において、第一条第一号から第三号までに掲げる業務（派遣先国の政府その他の関係機関と当該業務に従事する協力隊の隊員との間の連絡調整に係るものに限る。）を行う場合（二）　ウガンダ又はケニアに所在する空港の区域において、自衛隊の部隊等の業務に附帯する業務として、空路により自衛隊の部隊等の業務に従事する人員の輸送又は自衛隊の部隊等の業務に必要な物資の補給を行う場合。ただし、陸上の場所に留まって行う場合に限る。（三）　インド、カンボジア、シンガポール、スリランカ、タイ、フィリピン、ベトナム、マレーシア、モルディブ、ラオス、アラブ首長国連邦、オマーン、サウジアラビア、エチオピア、ジブチ又はセーシェルに所在する空港の区域において、自衛隊の部隊等の業務に附帯する業務として、空路により自衛隊の部隊等の業務に従事する人員の輸送又は自衛隊の部隊等の業務に必要な物資の補給を行う場合（五の項（一）本文に規定する場合及び防衛省の職員の給与等に関する法律施行令（昭和二十七年政令第三百六十八号）別表第五に定める海上警備等手当が支給される場合を除く。）。ただし、陸上の場所に留まって行う場合に限る。 | 三千円 |

| 五 | （一）　四の項（三）に規定する区域において、自衛隊の部隊等の業務に附帯する業務として、空路により乗員が自衛隊の部隊等の業務に従事する人員の輸送又は自衛隊の部隊等の業務に必要な物資の補給を行う場合（防衛省の職員の給与等に関する法律施行令別表第五に定める海上警備等手当が支給される場合を除く。）。ただし、陸上の場所に留まって行う場合に限る。（二）　ケニア又はジブチ内の地域において、自衛隊の部隊等の業務に附帯する業務として、海路により自衛隊の部隊等の業務に従事する人員の輸送又は自衛隊の部隊等の業務に必要な物資の補給を行う場合 | 千四百円 |
