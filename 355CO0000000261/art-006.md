（法第二十七条の技術的読替え）

第六条　法第三十条第七項の規定による技術的読替えは、次の表のとおりとする。

| 読み替える規定 | 読み替えられる字句 | 読み替える字句 |

| 第二十七条第八項 | 対内直接投資等又は国の安全等に係る措置に関する修正を行わなければならない | 技術導入契約の締結等をしなければならない |

| 第二十七条第九項 | 第三項若しくは第六項又は第二十七条の三第二項 | 第三十条第三項又は第六項 |

|  | これらの規定により延長された禁止期間の満了前であつても | 当該技術導入契約の締結等に係る届出を行つた日から起算して四月（同項の規定により延長された場合にあつては、五月）を経過しなくても |

|  | 対内直接投資等を行う | 技術導入契約の締結等をする |

| 第二十七条第十項 | 対内直接投資等に係る内容の変更、国の安全等に係る措置に関する修正又は当該対内直接投資等の | 技術導入契約の締結等に係る条項の全部若しくは一部の変更又は |

|  | 、国の安全等に係る措置に関する修正又は当該中止 | 又は中止 |

|  | 第三項若しくは第六項又は第二十七条の三第二項の規定により延長された禁止期間 | 当該届出を受理した日から起算して同条第三項又は第六項の規定により延長された期間 |

| 第二十七条第十一項 | 第一項の規定による届出に係る対内直接投資等が国の安全等に係る対内直接投資等 | 第三十条第一項の規定による届出に係る技術導入契約の締結等が同条第三項に規定する国の安全等に係る技術導入契約の締結等 |

| 対内直接投資等に係る内容の変更若しくは国の安全等に係る措置に関する修正 | 技術導入契約の締結等に係る条項の全部若しくは一部の変更 |

| 第二十七条第十二項 | 第五項から前項までに定めるもののほか、これらの規定による対内直接投資等に係る内容の変更、国の安全等に係る措置に関する修正又は対内直接投資等の | 第七項から前項まで並びに第三十条第五項及び第六項に定めるもののほか、技術導入契約の締結等に係る条項の全部若しくは一部の変更又は |
