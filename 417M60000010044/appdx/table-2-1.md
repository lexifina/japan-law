# 別表第二の一（第三条関係　法の適用対象のもの）

| 番号 | 保存 |

| 一 | 債権管理回収業に関する特別措置法（平成十年法律第百二十六号）第二十条の規定による帳簿書類の保存 |

| 二 | 裁判外紛争解決手続の利用の促進に関する法律（平成十六年法律第百五十一号）第十六条の規定による手続実施記録の保存 |

| 三 | 建物の区分所有等に関する法律第四十二条第五項において準用する同法第三十三条第一項の規定による議事録の保存（同法第六十六条、第七十三条及び第七十九条において準用する場合を含む。） |

| 四 | 司法書士法施行規則第四十九条第二項の規定による事件簿の保存 |

| 五 | 土地家屋調査士法（昭和二十五年法律第二百二十八号）第二十一条の規定による帳簿又は書類の保存（同法第四十一条第一項において準用する場合を含む。） |

| 六 | 土地家屋調査士法施行規則第四十七条第二項の規定による事件簿の保存 |

| 七 | 更生保護事業法（平成七年法律第八十六号）第十四条の二の規定による財産目録の保存 |

| 八 | 更生保護事業法第二十九条第一項の規定による事業成績書、財産目録、貸借対照表、収支計算書又は損益計算書の保存 |

| 九 | 更生保護事業法第三十五条第一項の規定による財産目録又は貸借対照表の保存 |

| 十 | 更生保護事業法第五十二条の規定による帳簿の保存（同法第五十六条の二第一項において準用する場合を含む。） |
