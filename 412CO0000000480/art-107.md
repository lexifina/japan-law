（清算人会に関する読替え）

第百七条　法第百五十四条の三第二項の規定において清算人会について法第百十三条及び第百十四条第一項の規定を準用する場合におけるこれらの規定に係る技術的読替えは、次の表のとおりとする。

| 読み替える法の規定 | 読み替えられる字句 | 読み替える字句 |

| 第百十三条第一項及び第二項 | 執行役員 | 清算執行人 |

| 第百十三条第三項及び第四項 | 監督役員 | 清算監督人 |

| 　 | 執行役員 | 清算執行人 |

| 第百十四条第一項 | 執行役員 | 清算執行人 |

| 読み替える会社法の規定 | 読み替えられる字句 | 読み替える字句 |
