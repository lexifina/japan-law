# 別表第一の二（第四条関係）

| 灯火の矢印の種類 | 灯火の矢印の形状 |

| 車両等が直進（令第二条第一項の多通行帯道路等通行一般原動機付自転車、特定小型原動機付自転車又は軽車両が右折しようとして右折する地点まで直進し、その地点において右折することを含む。）をすることができることとなるもの |    |

| 車両等が左折することができることとなるもの |    |

| 車両等（令第二条第一項の多通行帯道路等通行一般原動機付自転車、特定小型原動機付自転車及び軽車両を除く。）が右折し、又は転回することができることとなるもの |    |

| 備考　灯火の矢印の形状については、道路の形状により特別の必要がある場合にあつては、当該道路の形状に応じたものとすることができる。 |
