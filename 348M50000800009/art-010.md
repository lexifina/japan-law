## 第三節　特殊な船舶の航路における交通方法の特則

（巨大船に準じて航行に関する通報を行う船舶）

| 航路の名称 | 長さ |

| 浦賀水道航路 | 百六十メートル |

| 中ノ瀬航路 | 百六十メートル |

| 伊良湖水道航路 | 百三十メートル |

| 明石海峡航路 | 百六十メートル |

| 備讃瀬戸東航路 | 百六十メートル |

| 宇高東航路 | 百六十メートル |

| 宇高西航路 | 百六十メートル |

| 備讃瀬戸北航路 | 百六十メートル |

| 備讃瀬戸南航路 | 百六十メートル |

| 水島航路 | 七十メートル |

| 来島海峡航路 | 百六十メートル |
