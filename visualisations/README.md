# 20のグラフで見る日本の法令

[English](README.en.md)

すべての国の法令のグラフは global-law 全体から：[global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations)。ここでは日本のグラフだけを掲載しています。

このリポジトリのデータだけから描いた、日本の法令の20のグラフです。e-Gov 法令検索の現行法令8,982件（憲法、法律2,078件、政令2,320件、府省令4,085件など）を条ごとのファイルにした記録、e-Gov が保有する改正履歴の施行済みの版48,672と公布済み・未施行の版1,182、そして改正法令が各法令の本文に残した附則151,354件から作りました。

[`20-no-gurafu-de-miru-nihon-no-horei.html`](20-no-gurafu-de-miru-nihon-no-horei.html) をブラウザで開いてください。ページはデータをすべて含む一つのファイルで、ウェブからは d3 ライブラリとフォントだけを読み込みます。右上のボタンで言語（日本語・英語）と表示（ライト・ダーク）を切り替えられます。各グラフにはリポジトリ内の出典、件数、限界を記し、その下にすべての数値の表があります。図の要素にポインタを重ねると正確な値が表示されます。

グラフは記録の内容を示すもので、その理由を示すものではありません。

## グラフ

### I. 現行の法令

#### 1. 現行法令8,982件

種類ごとの現行法令と条の数：法律2,078件に対し、政令と府省令は合わせて6,405件。条の最も多い法令は地方税法（1,314条）。

![現行法令8,982件](stills/ja/01.png)

#### 2. 明治から令和まで

番号の年と元号ごとの現行法令：49%が平成、11%が令和の番号で、明治・大正の番号の法令も165件。最も古いのは1872年の改暦ノ布告。

![明治から令和まで](stills/ja/02.png)

#### 3. 文語の法令

1947年より前の番号を持つ現行法令263件のうち224件に、片仮名の文語体の条が残る（法律では71件）。平仮名に書き改められた民法、刑法、商法も。

![文語の法令](stills/ja/03.png)

#### 4. 枝番号

「第十四条の二」のような枝番号の条：法律の条の23%、金融商品取引法では1,101条のうち875条。

![枝番号](stills/ja/04.png)

#### 5. 災害と法令

題名に災害の名を持つ現行法令：東日本大震災は99件で、うち88件が2011年の番号。阪神・淡路大震災、熊本地震、能登半島地震、新型コロナウイルス感染症。

![災害と法令](stills/ja/05.png)

### II. 改正の百年

#### 6. 改正の記録

現行法令に残る改正法令の附則151,354件を、改正法令の年ごとに：最多は2000年の5,372件。

![改正の記録](stills/ja/06.png)

#### 7. 束ね法

附則を最も多くの現行法令に残した15の法律：平成11年法律第160号は883件、令和4年法律第68号は845件（現行の法律の40%）。

![束ね法](stills/ja/07.png)

#### 8. 改正の多い法律

本文に残る改正法令の附則の多い20の法律を、改正の年代別に：地方税法は940、現行の法律の中央値は9。

![改正の多い法律](stills/ja/08.png)

#### 9. 施行日の決め方

改正法律の附則の第一条を分類：施行日を政令に委ねる法律は、1947〜1959年の11%から2020年以降の42%へ。

![施行日の決め方](stills/ja/09.png)

### III. 施行の暦

#### 10. 4月1日

2018〜2025年に施行された版の日付をカレンダーに：29.2%が4月1日。改正法令が公布された曜日と、版が施行された曜日。

![4月1日](stills/ja/10.png)

#### 11. 公布から施行まで

公布から施行までの日数を改正法令の種類ごとに：法律による版は中央値283日、政令9日、府省令2日。

![公布から施行まで](stills/ja/11.png)

#### 12. 毎年3月末の税制改正

所得税法等の一部を改正する法律（2018〜2026年）：9本とも3月29〜31日に公布され、版の40%が4月1日に施行。

![毎年3月末の税制改正](stills/ja/12.png)

#### 13. 公布済み・未施行

施行を待つ1,182の版を施行予定の月ごとに：2027年4月1日だけで304。1976年公布の規定も、まだ施行日が定まっていない。

![公布済み・未施行](stills/ja/13.png)

### IV. 国会・内閣・府省

#### 14. 法律番号

年ごとの最大の法律番号と現行の法律：1952年は第358号まで、2025年は第96号まで。2019年は平成31年第1〜20号と令和元年第1〜74号。

![法律番号](stills/ja/14.png)

#### 15. 法律が公布される月

1947年以降、公布日のわかる法律7,408件を年と月ごとに：6月が23%、5月が19%。

![法律が公布される月](stills/ja/15.png)

#### 16. 議員立法

内閣提出の閣法と議員提出の衆法・参法：2010年代の番号を持つ現行の法律の44%は議員提出、基本法では54件中35件。

![議員立法](stills/ja/16.png)

#### 17. 府省令の発令者

現行の府省令を発令した府省ごとに：単独の府省令3,291件のうち1,527件は、番号が2000年以前で終わる府省のもの。

![府省令の発令者](stills/ja/17.png)

### V. 憲法と六法

#### 18. 憲法と六法

日本国憲法は1947年5月3日の本文のまま。六法の本文に残る改正法令の附則：民法67、商法66、刑事訴訟法63。

![憲法と六法](stills/ja/18.png)

#### 19. 条ごとに見た憲法と六法

各条の最後の改正の時期：e-Gov の記録の始まり以降、民法は446条、刑法は190条が書き換えられた。

![条ごとに見た憲法と六法](stills/ja/19.png)

#### 20. 民法と刑法の10年

条が改められた回数の累計：民法465回、刑法218回。最大は2020年4月1日の平成29年法律第44号（323条）。

![民法と刑法の10年](stills/ja/20.png)

## 限界

- **現行の法令だけです。** 廃止された法令は含まれないため、年や元号ごとの数は、現在まで残った法令の数です。
- **e-Gov の改正履歴は多くの法令で2016〜2017年からです。** グラフ10〜13、19、20はこの期間だけを示します。3,539件の法令は現行の本文だけで、過去の版はまだありません。
- **附則の索引は、e-Gov の本文に残る附則です。** 古い改正の附則を持たない法令があります（民法は1926年の改正のものから）。
- **分類は名前、題名、本文の規則によります。** 法律の提出者（法令ID）、施行期日の定め方、片仮名の文語体、災害の名、題名の形は `src/prep.py` の規則に従い、どの規則にも当てはまらないものは「その他」です。
- **版は本文を改めたものです。** 改正法令の附則が加わっただけの版はグラフ10〜12で除き、同じ日に同じ法令を改めた二つの改正は一つの版と数えます。
- **2026年は11月2日までです**（薄い色で示しています）。

## 再構築

```sh
python visualisations/src/make.py            # 履歴、ファイルの構成、附則と本文 -> src/.build/ -> 20-no-gurafu-de-miru-nihon-no-horei.html
node visualisations/src/stills.cjs           # この README の画像（Playwright が必要。グローバルにない場合は PLAYWRIGHT=<パス>）
```

`make.py` はすべてを git のオブジェクトから読むため、blob のないクローン（`--filter=blob:none`）や `--no-checkout` のクローンでも動きます。その場合に取得するのは、改正法律ごとの附則のファイル一つ、1947年より前の法令の条、憲法と六法の条、表（`laws.csv`、`corpus.json`、`data/laws.json`、`data/paths.json`、`data/revisions.json`）だけです（およそ2万の小さなファイル）。既定では `origin/main`（なければ `HEAD`）を読み、`--ref` で別のブランチやコミットを選べます。リポジトリにはページと `src/.build/` フォルダ（git は無視します）のほかには何も書き込みません。

| ファイル | 役割 |
| --- | --- |
| `src/make.py` | 履歴、ファイルの構成、附則と本文を `src/.build/` に取り出し、`prep.py` と `build.py` を実行する |
| `src/prep.py` | 20のグラフとデータの概要のすべての数値を `src/.build/data.json` に計算する |
| `src/page.tpl.html` | ページ：日英両方の文章、グラフ（d3）、表 |
| `src/build.py` | `data.json` をテンプレートに入れ、ページを書き出す |
| `src/stills.cjs` | 各グラフを PNG にして `stills/ja/` と `stills/en/` に描く |
