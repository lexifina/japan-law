# 別表第四（第百七条関係）

| 導管輸送工作物の種類 | 記載すべき事項 | 添付書類（届出に係る工事の内容に関係のあるものに限る。） |

| 一般記載事項 | 設備別記載事項（届出に係る工事の内容に関係のあるものに限る。） |

| 一　導管 |  | １　導管の始点及び終点の位置（都道府県郡市区町村字を記載すること。）２　延長（地中、水底及びその他の別に記載すること。）３　輸送する二酸化炭素の性状、常用の圧力及び温度　４　形状、主要寸法及び材料　５　接合の方法　６　水分除去措置の方法　７　防護措置の方法　８　防食措置の方法　９　二酸化炭素遮断装置の型式又は種類　１０　危険標識の内容　１１　計測装置及び警報装置の型式又は種類　１２　ベントスタックの種類、主要寸法及び材料 | １　導管の経路（地中、水底及びその他の別を表示すること。）、経過地の名称及び導管の付近に存する主要な道路、建築物その他の工作物及び導管に設置される次の事項の位置を明示した縮尺三千分の一以上の地形図（１）　水分除去措置を講ずる位置（２）　二酸化炭素遮断装置（３）　計測装置（４）　警報装置（５）　ベントスタック（６）　危険標識　２　導管に使用する材料が安全な化学的成分及び機械的性質を有するものであることの説明書　３　強度計算書　４　導管の構造図　５　接合部分の構造図　６　導管の耐震性に関する説明書　７　水分除去措置に関する説明書　８　衝撃に対する防護装置の構造図及び強度計算書　９　防食措置に関する説明書　１０　ベントスタックの構造図　１１　二酸化炭素による人の健康に係る被害防止措置に関する説明書　１２　温度又は圧力による伸縮吸収装置に関する説明書　１３　導管の設置方法に関する説明書 |

| 二　圧送機設置所 | 圧送機設置所の名称及び位置（都道府県郡市区町村字を記載すること。） |  | １　圧送機設置所の位置を明示した縮尺二万五千分の一以上の地形図　２　圧送機設置所の建物及び附属設備の構造図（これらの配置の状況が明らかとなるように図示すること。） |

| （一）　圧送機 |  | １　圧送する二酸化炭素の性状、圧力、温度及び常用の圧力　２　型式、主要寸法、材料、個数、能力及び吐出圧力　３　圧送機の基礎の状況　４　圧力計、安全装置、計測装置及び警報装置の型式又は種類　５　安全装置の取付箇所　６　外部強制潤滑油装置の種類 | １　圧送機に使用する材料が安全な化学的成分及び機械的性質を有するものであることの説明書　２　圧送機の構造図　３　圧送機の強度計算書　４　圧送機の気密な構造を確認する書類及び耐圧・気密性能試験成績書　５　安全装置の説明書　６　外部強制潤滑油装置の作動に関する説明書 |

| （二）　高圧ガス製造設備 |  | １　製造する高圧ガスの種類　２　一日に圧縮、液化その他の方法で処理することができるガスの容積（冷凍のためのものにあっては、一日の冷凍能力）３　材料、型式、主要寸法、能力及び配置　４　可燃性ガスの発生又は精製のための設備等における換気方法　５　圧縮機と高圧ガスを容器に充塡する場所又は容器置場との間の構造　６　バルブ類の開閉状態等の明示方法　７　安全装置の型式、種類又は取付箇所　８　基礎の状況 | １　高圧ガス製造設備（冷凍設備を除く。）を設置する室及び容器置場の位置並びに付近の状況を示す図面　２　高圧ガス製造設備の構造、設計図、配置図及び構造図　３　塔（反応、分離、精製、蒸留等を行う高圧ガス製造設備（貯槽を除く。）であって、当該設備の最高位の正接線から最低位の正接線までの長さが五メートル以上のものをいう。）、凝縮器（縦置円筒形で胴部の長さが五メートル以上のものに限る。）、貯槽（貯蔵能力が三百立方メートル又は三トン以上のものに限る。）及び受液器（内容積が五千リットル以上のものに限る。）並びにこれらの支持構造物及び基礎の構造図　４　強度計算（冷凍設備に用いる機器については、耐圧及び気密に関する性能）又は使用方法　５　安全装置の説明書 |
